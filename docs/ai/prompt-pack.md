Use these prompts when you want Copilot to plan or implement changes consistently.

## Planning

"Plan a feature update for workshop registration. Use blueprint/ design and specs. Output .copilot_temp/tasks.md."

"Implement the registration hold-then-pay flow with idempotency. Update specs and tests."

## Review

"Review changes for adherence to SOLID and DRY. Verify Zod validation and adapter pattern usage."

## Docs

"Update blueprint/ docs to reflect changes in payment retry policy and circuit breaker thresholds."
